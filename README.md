# MGMT 512 — Organizational Management Practice Test

A single-page study/practice-test site for MGMT 512 (Organizational Management), with an 1980s Miami Vice aesthetic. Built from class slides (Chapters 1–15).

## Features
- **Section 1 — Multiple Choice:** 20 questions drawn from a pool of 50, one at a time.
- **Section 2 — Short Answer:** 2 questions (model answer + self-grade).
- **Section 3 — Word Match:** 30-term word box drawn fresh from a ~49-term pool each attempt — 15 definitions to match plus 15 rotating decoys; drag-and-drop or tap-to-place.
- Weighted ~70% toward Class 5, 6 & 8 (Leading, Decision-Making, Teams, Motivation, Controls & Strategic HR).
- Score + full answer key, Save-as-PDF, retry with a fresh randomized set.
- Optional generated synthwave background loop (Web Audio API).

Everything runs client-side in `index.html` — no build step, no dependencies.
